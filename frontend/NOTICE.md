# Procedencia

Las entradas frontend-workflow, frontend-review, frontend-motion y la adaptación portable de sir-jony-ive se redactaron para esta selección. Las referencias conservan el texto de sus autores; SKILL.md se renombró a GUIDE.md y se retiró su metadata de invocación para que funcionen como lectura bajo demanda. No se ha validado cada ejemplo de API de terceros contra las versiones de Sialos.

Los árboles de referencias de Jakub Krehel y Emil Kowalski y las cuatro skills optativas conservan sus licencias MIT. La distribución de Impeccable se conserva con su licencia Apache 2.0 y sus scripts; no se ejecutaron sus instaladores, hooks ni motor. Su primera ejecución puede descargar el motor según sus instrucciones oficiales. Este perfil hace una copia manual de la skill; no configura hooks ni subagentes de Impeccable.

Los commits y enlaces de los cuatro repos están en sources.lock.json. El conocimiento de Sir Jony Ive se consulta desde su propio checkout y mantiene allí su estructura y mantenimiento.

Las optativas de Jakub tienen un encuadre añadido para reutilizar el banco de pruebas y el DS del producto; sus remisiones a better-* e interface-review se dirigen a frontend-review. Se corrigió un enlace SKILL.md a GUIDE.md en las recetas de choreograph tras el cambio de nombre. Estas son adaptaciones del paquete, no texto upstream intacto.
